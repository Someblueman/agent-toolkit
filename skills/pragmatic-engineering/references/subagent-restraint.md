# Delegation boundaries

Delegate only when authorized and a bounded independent investigation can run alongside useful local work. Keep linear investigations and small fixes local.

Assign exclusive edit ownership and require preservation of other changes. The primary agent inspects the returned diff, surrounding code and integrated result against the user's request. Reports and consensus are advisory; they do not replace acceptance evidence.

Stay within the approved scope and resource budget. Do not create new tasks, publish changes or expand a review campaign merely because tools support those actions.
